# 日历/日程模块 (lark-calendar) 运作计划

## 1. 模块概述

lark-calendar 用于安排项目会议、阶段汇报、技术评审等日程。日程是项目节奏的重要组成部分。

## 2. 日程类型

| 日程类型 | 频率 | 参与者 | 时长 | 用途 |
|---------|------|--------|------|------|
| 周会 | 每周一次 | 全员 | 1小时 | 进度同步、问题讨论 |
| 阶段汇报 | 每阶段末 | 全员 + 指导老师 | 1.5小时 | 阶段成果展示 |
| 技术评审 | 按需 | 相关人员 | 1小时 | 方案评审、代码审查 |
| 紧急会议 | 按需 | 相关人员 | 30分钟 | 紧急问题讨论 |
| 分享会 | 每阶段初 | 全员 | 1小时 | 技术分享、知识传递 |

## 4. 特殊日程场景

### 4.1 紧急会议

当群聊中出现严重 bug 或重大分歧时，安排紧急会议：

```
P1 陈卓远: 进程模型的分歧需要当面讨论，今天下午3点开个会
P7 张若琳: 我来创建日程
```

### 4.2 Deadline 提醒

在 deadline 前 2 天创建提醒日程：

```
P7 张若琳: @所有人 提醒：Phase 1 deadline 是本周五，大家抓紧
P7 张若琳: 我创建了一个明天的进度检查会
```

### 4.3 分享会

每个阶段开始时安排技术分享：

```
P1 陈卓远: Phase 3 要开始了，谁来分享一下进程调度的理论知识？
P3 赵一帆: 我来吧，我对 CFS 有一些研究
P7 张若琳: 好的，我创建日程，明天下午2点？
P3 赵一帆: 可以
```

## 5. 使用 lark-cli 操作日程

### 5.1 创建日程

```bash
lark-cli calendar +create --summary "Phase 1 周会" --start "2026-03-14T16:00:00+08:00" --end "2026-03-14T17:00:00+08:00" --description "Phase 1 进度同步和问题讨论" --as user
```

### 5.2 添加参会人

```bash
lark-cli calendar events patch --event-id $EVENT_ID --add-attendees "$OPEN_ID1,$OPEN_ID2" --as user
```

### 5.3 查询日程

```bash
lark-cli calendar +agenda --start "2026-03-14" --end "2026-03-14" --as user
```

### 5.4 查询忙闲

```bash
lark-cli calendar +freebusy --user-id $OPEN_ID --start "2026-03-14T16:00:00+08:00" --end "2026-03-14T17:00:00+08:00" --as user
```

## 6. 日程与群聊的联动

### 6.1 日程创建触发

当群聊中出现以下消息时，触发日程创建：
- "开个会讨论一下" -> 创建日程
- "明天下午有空吗？" -> 查询忙闲后创建日程
- "这个需要评审" -> 创建技术评审日程

### 6.2 日程提醒

在日程开始前 15 分钟，在群聊中发送提醒：
```
P7 张若琳: @所有人 提醒：10分钟后开始 Phase 1 周会
```

### 6.3 会议纪要

日程结束后，由 P7 在群聊中发送会议纪要摘要：
```
P7 张若琳: 刚才的周会纪要：
P7 张若琳: 1. P2 完成了 ELF 加载的核心代码
P7 张若琳: 2. 串口驱动遇到问题，P2 会继续调试
P7 张若琳: 3. 下周目标：完成 Bootloader 和串口驱动
P7 张若琳: 详细纪要已更新到文档
```

## 7. 时间冲突处理

### 7.1 冲突检测

创建日程前，先查询所有参与者的忙闲状态：
```bash
lark-cli calendar +freebusy --user-id $OPEN_ID --start $START --end $END --as user
```

### 7.2 冲突解决

如果发现冲突，在群聊中讨论替代时间：
```
P7 张若琳: 周五下午3点 P3 有课，改到4点可以吗？
P3 赵一帆: 4点可以
P7 张若琳: 好的，已更新日程
```
