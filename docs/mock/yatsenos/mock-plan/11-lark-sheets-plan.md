## 3. 使用 lark-cli 操作电子表格

### 3.1 创建电子表格

```bash
lark-cli sheets +create --title "YatSenOS 项目进度表" --as user
```

### 3.2 写入表头

```bash
lark-cli sheets +write --spreadsheet-token $TOKEN --range "Sheet1!A1:H1" --values '[["阶段","计划开始","计划结束","实际开始","实际结束","完成度","状态","负责人"]]' --as user
```

### 3.3 追加数据

```bash
lark-cli sheets +append --spreadsheet-token $TOKEN --range "Sheet1!A:H" --values '[["Phase 0","03/02","03/13","","","0%","Not Started","P1"]]' --as user
```

### 3.4 更新数据

```bash
lark-cli sheets +write --spreadsheet-token $TOKEN --range "Sheet1!G2" --values '[["In Progress"]]' --as user
```

### 3.5 读取数据

```bash
lark-cli sheets +read --spreadsheet-token $TOKEN --range "Sheet1!A1:H10" --as user
```

## 4. 电子表格更新时机

### 4.1 每周更新

- 更新阶段进度
- 更新议题进度
- 更新测试覆盖率

### 4.2 里程碑更新

- 更新完成度
- 更新状态

### 4.3 阶段结束

- 更新实际结束日期
- 更新最终完成度
- 更新测试覆盖率
