# 视频会议模块 (lark-vc) 运作计划

## 1. 模块概述

lark-vc 用于记录项目中的视频会议，包括周会、技术评审、分享会等。

## 2. 会议类型与频率

| 会议类型 | 频率 | 时长 | 参与者 | 是否录制 |
|---------|------|------|--------|---------|
| 周会 | 每周五 | 1小时 | 全员 | 是 |
| 阶段汇报 | 每阶段末 | 1.5小时 | 全员 | 是 |
| 技术评审 | 按需 | 1小时 | 相关人员 | 是 |
| 分享会 | 每阶段初 | 1小时 | 全员 | 是 |
| 紧急会议 | 按需 | 30分钟 | 相关人员 | 否 |

类似模式，每个阶段包含：
- 启动会（1 次）

- 技术评审（0-2 次）
- 阶段汇报（1 次）

## 4. 会议纪要内容

### 4.1 周会纪要内容

- 各成员进度汇报
- 遇到的问题和解决方案
- 下周计划
- 需要协调的事项

### 4.2 阶段汇报内容

- 阶段目标回顾
- 成果展示（Demo）
- 问题和改进
- 下阶段计划

### 4.3 技术评审内容

- 方案介绍
- 讨论和质疑
- 决策记录
- 后续行动

## 5. 使用 lark-cli 操作视频会议

### 5.1 搜索会议记录

```bash
lark-cli vc +search --start "2026-03-07" --end "2026-03-07" --as user
```

### 5.2 获取会议纪要

```bash
lark-cli vc +notes --meeting-id $MEETING_ID --as user
```

### 5.3 获取会议录制

```bash
lark-cli vc +recording --meeting-id $MEETING_ID --as user
```

## 6. 会议与群聊的联动

### 6.1 会议通知

在群聊中发送会议通知：
```
P7 张若琳: @所有人 提醒：明天下午2点 Phase 1 启动会
P7 张若琳: 会议链接：[链接]
P7 张若琳: 请大家准时参加
```

### 6.2 会议纪要分享

会议结束后，在群聊中分享纪要：
```
P7 张若琳: 刚才的周会纪要已整理好
P7 张若琳: 主要内容：
P7 张若琳: 1. P2 完成了 ELF 加载
P7 张若琳: 2. 串口驱动遇到问题
P7 张若琳: 3. 下周目标：完成 Bootloader
P7 张若琳: 详细纪要：[文档链接]
```

### 6.3 会议录制回放

如果需要回顾会议内容：
```
P3 赵一帆: 上次周会的讨论我记不太清了，有录制吗？
P7 张若琳: 有的，妙记链接：[链接]
```
