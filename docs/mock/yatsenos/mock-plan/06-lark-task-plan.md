# 任务模块 (lark-task) 运作计划

## 1. 模块概述

lark-task 用于跟踪项目任务的创建、分配、执行和完成。每个阶段对应一组任务，每个议题对应一个主任务，每个决策点对应一个子任务。

## 2. 任务结构设计

### 2.1 任务层级

```
阶段主任务 (Task List)
├── 议题任务 (Task)
│   ├── 决策子任务 (Subtask)
│   └── 决策子任务 (Subtask)
└── 议题任务 (Task)
    ├── 决策子任务 (Subtask)
    └── 决策子任务 (Subtask)
```

### 2.2 任务清单命名

| 阶段 | 任务清单名称 |
|------|------------|
| Phase 0 | YatSenOS - Phase 0: 基础设施搭建 |
| Phase 1 | YatSenOS - Phase 1: 引导加载器 |
| Phase 2 | YatSenOS - Phase 2: 中断与异常处理 |
| Phase 3 | YatSenOS - Phase 3: 进程调度引擎 |
| Phase 4 | YatSenOS - Phase 4: 用户态运行时 |
| Phase 5 | YatSenOS - Phase 5: 并发与同步原语 |
| Phase 6 | YatSenOS - Phase 6: 存储子系统 |
| Phase 7 | YatSenOS - Phase 7: 内存管理优化 |
| Phase 8 | YatSenOS - Phase 8: 特性扩展冲刺 |

## 3. 任务创建时机

### 3.1 阶段开始时

每个阶段开始时（在群聊启动讨论之后），由 P1 或 P7 创建：
1. 任务清单
2. 议题级主任务（每个议题一个）
3. 决策级子任务（每个决策点一个）

### 3.2 讨论中追加

当群聊讨论中出现新的问题或决策点时，追加子任务。

### 3.3 阶段结束时

标记所有任务为完成，创建阶段总结任务。

## 5. 任务状态管理

### 5.1 状态流转

```
创建 (Created) -> 进行中 (In Progress) -> 完成 (Done)
                 -> 阻塞 (Blocked) -> 进行中 (In Progress) -> 完成 (Done)
```

### 5.2 状态更新时机

- 任务开始时：群聊中有人说"这个我来吧" -> 状态改为"进行中"
- 遇到阻塞时：群聊中有人说"被xxx卡住了" -> 状态改为"阻塞"
- 任务完成时：群聊中有人说"搞定了"或"PR提了" -> 状态改为"完成"

## 6. 使用 lark-cli 操作任务

### 6.1 创建任务清单

```bash
lark-cli task tasklists create --summary "YatSenOS - Phase 0: 基础设施搭建" --as user
```

### 6.2 创建主任务

```bash
lark-cli task +create --summary "统一开发环境" --description "确定并统一团队开发环境" --as user --due "2026-03-08T18:00:00+08:00"
```

### 6.3 创建子任务

```bash
lark-cli task +create --summary "确定统一开发环境方案" --parent $PARENT_TASK_GUID --as user --due "2026-03-03T18:00:00+08:00"
```

### 6.4 更新任务状态

```bash
lark-cli task +update --guid $TASK_GUID --completed true --as user
```

### 6.5 添加任务成员

```bash
lark-cli task members create --guid $TASK_GUID --id $OPEN_ID --type assignee --as user
```

## 7. 任务与群聊的联动

### 7.1 任务创建触发

当群聊中出现以下消息时，触发任务创建：
- "这个谁来跟一下？" -> 创建任务并分配
- "我觉得需要做..." -> 创建任务
- "@某人 你负责..." -> 创建任务并分配给该人

### 7.2 任务完成触发

当群聊中出现以下消息时，更新任务状态：
- "搞定了" -> 标记任务完成
- "PR 提了" -> 标记任务完成
- "测试通过了" -> 标记任务完成

### 7.3 任务阻塞触发

当群聊中出现以下消息时，更新任务状态：
- "被xxx卡住了" -> 标记任务阻塞
- "这个依赖xxx" -> 标记任务阻塞
- "需要等xxx先完成" -> 标记任务阻塞
