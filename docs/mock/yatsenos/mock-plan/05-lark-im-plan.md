# 即时通讯模块 (lark-im) 运作计划

## 1. 模块概述

lark-im 是整个模拟数据的核心模块，群聊消息是其他模块触发的基础。所有的任务创建、日程安排、文档编写等操作都源于群聊中的讨论。

| YatSenOS 总群聊 | YATSENOS_CHAT_ID | 全员通知、阶段汇报、跨阶段讨论 |
| YatSenOS-Lab0 | YATSENOS_LAB0_CHAT_ID | Phase 0 基础设施搭建 |

## 3. 消息发送策略

### 3.1 每日消息量

| 时段 | 工作日消息量/群 | 周末消息量/群 |
|------|---------------|-------------|
| 上午 (9:00-12:00) | 3-5 条 | 0-1 条 |
| 下午 (13:00-18:00) | 5-8 条 | 0-2 条 |
| 晚上 (19:00-23:00) | 2-4 条 | 0-1 条 |

### 3.2 消息发送节奏

- 每个阶段的第1天：启动讨论（5-10条消息）
- 每个阶段中期：技术讨论高峰期（每天 10-15 条）
- 每个阶段末期：收尾和总结（5-8条）
- 临近 deadline：消息量翻倍

### 3.3 消息内容分布

每个阶段群聊的消息分布：
- 议题相关讨论：40%
- 决策与确认：15%
- 进度同步：15%
- 代码审查：10%
- 闲聊废话：15%
- 通知公告：5%

## 4. 使用 lark-cli 发送消息

### 4.1 发送文本消息

```bash
lark-cli im +send --chat-id $CHAT_ID --as user --content "消息内容"
```

### 4.2 发送富文本消息

```bash
lark-cli im +send --chat-id $CHAT_ID --as user --msg-type post --content '{
  "zh_cn": {
    "title": "标题",
    "content": [[{"tag": "text", "text": "内容"}]]
  }
}'
```

### 4.3 回复消息

```bash
lark-cli im +reply --message-id $MSG_ID --as user --content "回复内容"
```

## 5. 各阶段群聊消息计划

### 5.1 Phase 0 群聊 (Lab0)

**启动讨论 (Day 1)**:
- P1 发送项目启动通知
- 每人自我介绍
- P1 分配初始任务
- P7 创建 Wiki 开发环境指南

**环境搭建 (Day 2-3)**:
- 各成员报告环境搭建进度
- 技术问题讨论（QEMU 启动、Rust 安装）
- P1 安排 Rust 分享会

**Rust 培训 (Day 4-5)**:
- 分享会通知
- Rust 练习讨论
- 代码 review

**UEFI 验证 (Day 6-7)**:
- Hello World 程序运行
- 调试环境搭建
- 阶段总结

### 5.2 Phase 1 群聊 (Lab1)

**启动 (Week 2)**:
- P1 介绍 Phase 1 目标
- P2 讲解 ELF 加载流程
- 方案讨论

**核心开发 (Week 2-3)**:
- Bootloader 实现讨论
- 串口驱动设计
- 调试技巧分享

**收尾 (Week 4)**:
- 测试结果汇报
- Bug 修复讨论
- 文档更新

### 5.3 Phase 2-8 群聊

类似模式，每个阶段包含：
1. 启动讨论（目标和分工）
2. 核心开发（技术讨论和问题解决）
3. 代码审查（PR review 和 bug 修复）
4. 阶段总结（成果汇报和经验分享）
