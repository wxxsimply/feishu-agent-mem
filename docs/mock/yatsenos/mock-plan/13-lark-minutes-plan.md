# 妙记模块 (lark-minutes) 运作计划

## 1. 模块概述

lark-minutes 用于管理视频会议的录制产物，包括 AI 生成的总结、待办、章节等。

## 2. 妙记使用场景

### 2.1 会议录制

每次视频会议（周会、阶段汇报、技术评审）都会自动录制并生成妙记。

### 2.2 妙记内容

每个妙记包含：
- 视频/音频录制
- AI 生成的总结
- AI 生成的待办
- AI 生成的章节
- 逐字稿

### 2.3 妙记使用

- 回顾会议讨论内容
- 提取会议决策
- 生成会议纪要
- 查找特定讨论片段

## 3. 妙记与会议的对应关系

| 会议 | 妙记 | 用途 |
|------|------|------|
| Phase 0 周会 | 有 | 记录环境搭建讨论 |
| Phase 1 启动会 | 有 | 记录方案设计讨论 |
| Phase 1 周会 #1 | 有 | 记录进度同步 |
| Phase 1 阶段汇报 | 有 | 记录成果展示 |
| ... | ... | ... |

## 4. 使用 lark-cli 操作妙记

### 4.1 搜索妙记

```bash
lark-cli minutes +search --query "Phase 1" --as user
```

### 4.2 获取妙记详情

```bash
lark-cli minutes +info --minute-token $MINUTE_TOKEN --as user
```

### 4.3 获取妙记 AI 产物

```bash
lark-cli minutes +ai-content --minute-token $MINUTE_TOKEN --as user
```

### 4.4 下载妙记音视频

```bash
lark-cli minutes +download --minute-token $MINUTE_TOKEN --output ./downloads/ --as user
```

## 5. 妙记与群聊的联动

### 5.1 妙记分享

会议结束后，在群聊中分享妙记：
```
P7 张若琳: 刚才的会议妙记已生成
P7 张若琳: AI 总结：讨论了 Phase 1 的设计方案，确定了 ELF 加载方案
P7 张若琳: 待办：P2 完成串口驱动，P6 搭建调试环境
P7 张若琳: 妙记链接：[链接]
```

### 5.2 妙记回顾

当需要回顾之前的讨论时：
```
P3 赵一帆: 我记得上次周会讨论过进程模型的问题，具体说了什么来着？
P7 张若琳: 我查一下妙记... 上次讨论的是 Linux 式 vs NT 式的设计
P7 张若琳: 最终决定用 Linux 式，原因是实现简单
```

### 5.3 待办提取

从妙记中提取待办并创建任务：
```
P7 张若琳: 我从妙记里提取了几个待办：
P7 张若琳: 1. P2 完成串口驱动 - 截止 03/20
P7 张若琳: 2. P6 搭建调试环境 - 截止 03/22
P7 张若琳: 已经创建了对应的任务
```
