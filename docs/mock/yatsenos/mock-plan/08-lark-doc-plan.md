# 云文档模块 (lark-doc) 运作计划

## 1. 模块概述

lark-doc 用于创建和管理项目文档，包括设计文档、会议纪要、代码审查记录、技术方案等。

## 2. 文档类型与创建时机

| 文档类型 | 创建时机 | 作者 | 用途 |
|---------|---------|------|------|
| 项目计划书 | Phase 0 开始 | P1 | 项目整体规划 |
| 阶段设计文档 | 每阶段开始 | 阶段负责人 | 技术方案设计 |
| 会议纪要 | 每次会议后 | P7 | 记录讨论和决策 |
| 代码审查记录 | PR review 后 | P6 | 记录审查意见 |
| 测试报告 | 每阶段结束 | P6 | 测试结果汇总 |
| 阶段总结 | 每阶段结束 | P1 | 成果和经验总结 |

## 5. 使用 lark-cli 操作文档

### 5.1 创建文档

```bash
lark-cli docs +create --api-version v2 --title "引导加载器设计文档" --content '<h1>引导加载器设计文档</h1><h2>1. 概述</h2><p>...</p>' --as user
```

### 5.2 更新文档

```bash
lark-cli docs +update --api-version v2 --doc $DOC_TOKEN --command append --content '<h2>新增章节</h2><p>内容</p>' --as user
```

### 5.3 搜索文档

```bash
lark-cli docs +search --query "设计文档" --as user
```

### 5.4 获取文档内容

```bash
lark-cli docs +fetch --api-version v2 --doc $DOC_TOKEN --as user
```

## 6. 文档与群聊的联动

### 6.1 文档创建触发

当群聊中出现以下消息时，触发文档创建：
- "我写了个设计文档" -> 创建设计文档
- "会议纪要我来整理" -> 创建会议纪要
- "这个方案需要评审" -> 创建评审文档

### 6.2 文档更新通知

文档更新后，在群聊中通知：
```
P7 张若琳: 我更新了 Phase 1 设计文档，补充了串口驱动的设计方案
P7 张若琳: 文档链接：[链接]
```

### 6.3 文档 review

在群聊中讨论文档内容：
```
P2 林晓薇: @P7 我看了设计文档，有几个地方需要修改
P2 林晓薇: 1. ELF 加载流程的描述不太准确
P2 林晓薇: 2. 缺少页表映射的说明
P7 张若琳: 好的，我马上改
```
